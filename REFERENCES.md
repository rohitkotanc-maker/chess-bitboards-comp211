# Further Reading and References

The following resources explain bitboards, board representation, and the magic-bitboard approach. These are included as references for the technical concepts; only claim to have personally read a resource if you have done so.

- Chess Programming Wiki — [Bitboards](https://www.chessprogramming.org/Bitboards): bitboard fundamentals, shift operations, attack sets.
- Chess Programming Wiki — [Board Representation](https://www.chessprogramming.org/Board_Representation): traditional and bitboard representations of chess positions.
- Chess Programming Wiki — [Magic Bitboards](https://www.chessprogramming.org/Magic_Bitboards): blocker masks, multiplicative indexing, attack lookup tables.
- C reference — [`uint64_t` and fixed-width integer types](https://en.cppreference.com/w/c/types/integer): fixed-width integer types in C.

The source examples in `src/` were prepared for this project as simple demonstrations and are not copied from these references.
